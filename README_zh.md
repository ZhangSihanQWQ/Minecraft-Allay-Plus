# AllayPlus

[![Minecraft Version](https://img.shields.io/badge/Minecraft-1.21.1-brightgreen.svg)](https://www.minecraft.net/)
[![Platform](https://img.shields.io/badge/Platform-Fabric-blue.svg)](https://fabricmc.net/)

**AllayPlus** 是一款在原版基础上增强悦灵（Allay）功能的 Fabric 模组。它不仅赋予了悦灵更智能、更宽泛的物品搜集分类逻辑，还通过重构底层 AI 机制，实现了服务器性能优化与自由可配置的规则系统。

---

## 核心特性

### 1. 模糊物品分类
打破了原版悦灵对“完全相同物品”的刻板定义，实现的搜集逻辑：

* **药水系统**：忽略药水效果（如力量、生命恢复）和持续时间，仅根据容器类型区分（普通/喷溅/滞留）。
* **音乐唱片**：悦灵现在热爱所有音乐，会将所有类型的唱片归为一类。
* **旗帜图案**：不再区分具体图案样式，只要是旗帜图案均可一并搜集。
* **船与运输船**：不再区分木材材质（如橡木、竹制等），仅区分普通船与运输船。
* **马铠**：现在所有材质的马铠将被分为一类。
* **床**：现在所有颜色的床将被分为一类。
* **陶片**：不同花纹的陶片将会被视为一类。
* **锻造模版**：所有锻造模版会被分为一类，同时包含下界合金升级和所有纹饰模板。

### 2. 极致性能优化
针对大规模悦灵聚集导致的 MSPT 飙升问题，模组引入了简单的优化策略：

  * 逻辑每 **20 ticks**（1秒）运行一次低频检查，降低判定负担。
  * **动态记忆屏蔽**：若视线内没有玩家，系统会暂时屏蔽 `LIKED_PLAYER` 记忆，并确保在没有 `LIKED_NOTEBLOCK` 任务时使悦灵进入自由寻路状态。这有效避免了在小空间内堆叠大量悦灵对玩家进行寻路而造成的计算压力。

### 3. 自定义规则系统
模组新增了多项可配置规则。修改这些规则需要 **2 级指令权限（管理员）**。

| 规则名称 | 指令用法 | 功能说明 | 默认值 |
| :--- | :--- | :--- | :--- |
| **静音共振** | `/allayplus silentResonanceEnabled <true\|false>` | 开启后，被方块阻挡的“静音”音符盒在被激活时也会触发悦灵的响应逻辑。 | `false` |
| **投掷冷却** | `/allayplus throwCooldownTime <ticks>` | 自定义悦灵投掷后的捡拾冷却。设置为 `0` 为无冷却，`-1` 为原版逻辑。 | `-1` |

> **注意**：关于 `throwCooldownTime` 的设置，不建议将其设置过短（如 0-5 ticks），否则悦灵可能会在投掷出物品的瞬间将其重新捡起，导致无法正常将物品投递给音符盒或漏斗。

## 安装要求

* **游戏版本**: `1.21.1`
* **加载器**: `Fabric Loader >= 0.16.14`
* **依赖**: `Fabric API`
